# DIMIR "RITUAL TEMPO" + THE FANTASTICAR — explosive fast-mana variant of Dimir Tempo
# Leans into Dark Ritual + Lotus Petal + Barrowgoyf + The Fantasticar: a disruptive tempo deck
# that can curve-cheat a threat a turn early (T1 Fantasticar / Barrowgoyf, T2 Kaito) behind
# Force + Daze + Thoughtseize. This is a PIVOT off stock Dimir Tempo, not a tune — it trades
# Murktide (a bad ritual target, fights the low curve) and shaves lands/Wasteland for fast mana.
#
# HONEST NOTES:
#  - Fantasticar is the real ritual payoff: a FIXED 4/4 flyer the moment it lands, graveyard-free,
#    dodges sorcery-speed removal (creature only when you choose). Ritual/Petal cast it turn 1-2.
#  - Barrowgoyf is */1+* (power = card types in all graveyards) — small on an EMPTY board, so a
#    T1 ritual-Barrowgoyf is a ~1/2 deathtoucher. It wants a LATE graveyard; it is the WEAK half
#    of the ritual plan. Kept because deathtouch+lifelink is still fine and it grinds late.
#  - Dark Ritual / Lotus Petal are card disadvantage a fair deck normally avoids; justified only
#    by the explosive curve-out + protect plan. This is a fringe build — rep-test before trusting.
