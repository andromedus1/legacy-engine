## Summary

Tibshirani, Walther & Hastie (2001), "Estimating the number of clusters in a data set via the gap
statistic" (JRSS-B 63(2)). The gap statistic estimates the number of clusters by comparing observed
within-cluster dispersion against that expected under a reference null distribution — an
information-grounded alternative to eyeballing a dendrogram cut or a silhouette peak.

## Key passages

- Method: "The technique uses the output of any clustering algorithm (e.g. K-means or hierarchical),
  comparing the change in within-cluster dispersion with that expected under an appropriate
  reference null distribution."
