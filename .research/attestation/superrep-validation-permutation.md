# Permutation Tests for Studying Classifier Performance

## Summary

Ojala and Garriga study permutation-based null distributions for classifier performance. One test
permutes class labels to ask whether a classifier has learned outcome structure; another performs a
restricted within-class feature permutation to ask whether feature dependencies contribute useful
information. Their experiments illustrate how rerunning the complete evaluation under a destroyed
relationship can distinguish apparent performance from exploitable structure.

## Key passages

1. The label-permutation test estimates a null distribution in which data points and labels have no
   association (abstract).
2. A restricted permutation can test whether a classifier exploits dependencies among features
   rather than only marginal feature distributions (abstract).
3. The paper evaluates the permutation procedures on both real and synthetic data (abstract).
