# Posterior Predictive Assessment of Model Fitness via Realized Discrepancies

## Summary

Gelman, Meng, and Stern develop posterior predictive checks that compare observed discrepancy
statistics with their distribution under replicated data generated from the fitted model. The
framework permits discrepancies that depend on unknown parameters and emphasizes graphical and
diagnostic checks as part of iterative model building. The authors caution that a model's passing a
posterior predictive check does not establish that the model is true or adequate for every purpose.

## Key passages

- §1–2: posterior predictive assessment compares realized discrepancies in observed data against
  replicated-data distributions under the model.
- §6, PDF p. 53: “Any model should be checked using graphical displays and diagnostic checks.”
- §6, PDF p. 53: posterior predictive assessment calibrates those checks and should indicate which
  model improvements to develop and test.
- §6, PDF p. 53: the authors caution against rejecting a model absolutely when no better alternative
  exists, and against accepting a model merely because it passes the checks.
