# Conventions — legacy-engine

Substrate conventions for the agile-workflow `.work/` layer. Generated by `/agile-workflow:convert`
(bootstrap), 2026-05-29.

## Release mapping
**tag-based** — items bind to a version at release time (`/agile-workflow:release-deploy <version>`);
the release ships by tagging the commit (e.g. `v0.1.0`). All work flows through `main` via PRs;
CI must be green before merge. Late-binding: don't pre-bind items to a version.

## Tag taxonomy
Tags route items to design skills and label work. `[refactor]` and `[perf]` have **load-bearing
routing semantics** — get them right.

| Tag | Semantic |
|-----|----------|
| `ingestion` | Data acquisition: Scryfall, the fbettega cache, vendored MTGOFormatData rules, ban-list snapshots, DuckDB load |
| `archetype` | The rule-based archetype classifier (ported MTGOArchetypeParser matcher, colors, labeler, golden tests) |
| `analytics` | Meta & Performance: meta-share, matchup matrix, trends, charts |
| `advisory` | Meta Attack/Advisory: positioning score, sideboard recommender, what-to-play, the field-read report |
| `goldfish` | Deck Mechanics pillar (deferred): mana solver, London-mulligan Monte-Carlo, clocks, meta-speed |
| `generation` | Deck Generation pillar (deferred): gap discovery, build tuning |
| `needs-brief` | Item requires a domain brief before design (run `/research-pipeline:brief` first) |
| `docs` | Documentation / rolling-foundation alignment work |
| `infra` | Tooling, CI, packaging, dev-environment |
| `refactor` | **Behavior-preserving structural change ONLY** (black-box test: no observable behavior change for a caller). Routes to `refactor-design`. |
| `perf` | Performance work (throughput, latency, memory). Routes to `perf-design`. |

## Slug conventions
kebab-case. Children carry a parent prefix (`epic-<slug>` → `<epic-slug>-<feature-slug>` →
`<feature-slug>-<story-slug>`).

## Stage overrides
None. Standard stages: `drafting → implementing → review → done` (releases: `planned → quality-gate →
released`).

## Gate config
`gates_for_release: [tests, cruft, docs, patterns]`

(security and infra gates omitted — legacy-engine is a local analytics CLI with no deployed
infrastructure and no auth/secrets surface. Revisit if that changes.)

## Design-skill routing
The `research-pipeline` plugin is installed, so autopilot dispatches the research-grounded,
`[needs-brief]`-gated design skills:
`design_skill_routing: { epic_design: research-pipeline:epic-design, feature_design: research-pipeline:feature-design }`
