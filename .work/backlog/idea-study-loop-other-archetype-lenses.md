# Run the study loop through non-Dimir archetype lenses

Andrew (2026-07-04, reviewing the copy-count study): the study's findings sit very much in
the lens of the Dimir Tempo archetype. The same study loop (sweep → divergence clusters →
distribution-first analysis → engine build ideas) applied to other decks — **especially
archetypes that play very differently from Dimir Tempo** (combo like TES/Oops, prison like
Lands/Tron, creature decks like Death & Taxes) — would generate a lot of good build ideas
for the engine. Each archetype lens stresses different scorer mechanics (plan cards vs
answers, lock pieces, mana denial, tax effects), so the error classes it surfaces should
differ too. Relates to [[idea-dogfood-loop-as-autonomous-process]] (this is the
generalized loop's payoff) and the sweep harness (feature-archetype-sweep-backtest, done)
which already produces the per-archetype raw material.
